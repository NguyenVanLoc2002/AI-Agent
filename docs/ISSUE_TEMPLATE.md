# Issue template
- ID, title, source requirement, actor, tenant/customer ownership
- Preconditions / states / business rules / alternative failures
- Sensitive data involved and egress allowed
- In scope/out of scope, API and migration assumptions
- Given/When/Then acceptance (happy, unauthorized, timeout, replay, concurrent)
- Evidence: test commands, logs with redaction, reviewed threat cases
- Done: tests run, code review, docs/decisions updated, safe rollback
