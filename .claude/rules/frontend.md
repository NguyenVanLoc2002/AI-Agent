# Frontend rules
- Follow `docs/03_UI_UX_Stitch.md` and approved design tokens; use semantic accessible HTML.
- Show distinction: AI-recognized / catalog lookup / verified SKU.
- Never calculate authoritative quote values or bypass backend approval.
- Handle blocked, empty, error, loading, expired, stale-version and handoff states.
- Sensitive Security Inspector views are role-gated by backend even if hidden in UI.
