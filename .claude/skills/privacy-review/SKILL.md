# Procedure
Trace source → DTO → tool result → egress/log/storage. Enumerate denylist, potential bypasses, negative tests and evidence. Never print secrets.

## Output
Record assumptions, work performed, actual test commands/outcomes, security concerns and next suggested task. Follow `CLAUDE.md` and `.claude/rules/`.
