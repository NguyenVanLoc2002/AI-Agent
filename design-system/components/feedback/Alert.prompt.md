Inline banner for page/section-level system state (ERP degraded, validation summary, permission notice).

```jsx
<Alert tone="warning" title="ERP phản hồi chậm" action={<Button size="sm" variant="secondary" iconLeft="refresh-cw">Thử lại</Button>}>Giá hiển thị được lưu lúc 09:42.</Alert>
```

Icon is always present. Use EmptyState when the whole region has no data.
